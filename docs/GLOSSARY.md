# BookPasal Domain Glossary

## Core Entities & Concepts

- **Book**: Item listed for sale on BookPasal (academic, curriculum, textbook, novel, etc.). Can be New or Used.
- **Listing**: The seller's offer of a book including condition, edition, photos, price in NPR, and location.
- **Order Group**: Grouping of order items purchased together by a buyer.
- **Buyer**: User purchasing books on BookPasal.
- **Seller**: User listing books for sale on BookPasal.
- **NPR**: Nepalese Rupee (Rs / NPR), the sole transaction currency.
- **Mobile-first PWA**: Progressive Web App optimized for mobile viewports, touch targets, and low-bandwidth connections.
